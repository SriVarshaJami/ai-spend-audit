# AI Spend Audit

AI cost optimization audit tool built with Next.js.

## Features

- AI spend calculator
- Savings estimation
- Shareable audit URL
- Results dashboard
- Supabase integration
- Automated tests

## Tech Stack

- Next.js
- TypeScript
- Supabase
- Vercel
- Vitest
